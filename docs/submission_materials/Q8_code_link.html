Project Description

The SEC EDGAR Facts Explorer is a 14-tool MCP server and IBM watsonx Orchestrate agent that answers questions about public company SEC filings — things like "What was Apple's revenue last quarter?" or "Which filing first reported Microsoft's most recent net income?" — by calling the SEC's official EDGAR APIs directly, so every number is traceable back to the primary source filing.

The MCP server (sec_edgar_tools) is deployed as an always-warm HTTPS service on IBM Code Engine using FastMCP. It wraps four distinct SEC EDGAR API endpoints and exposes them as 14 structured tools over the streamable_http transport. No API keys are required — EDGAR is fully open. The watsonx Orchestrate agent (sec_edgar_agent) uses a detailed instruction set with 14 routing rules, synonym resolution, fiscal-year comparability warnings, and a prohibition on constructing or guessing URLs.
